A newspaper front page that sums up Tuesday 17 November 2026 in one image. Four stories: the Kerch bridge hit, tankers on fire near Hormuz, the Xi, Trump and Putin talks, and the Rwanda returns hub, plus a footer with three more items from the day. The program draws the whole page itself with a hand-built bitmap font and its own PNG encoder, using only the Python standard library.

## Run it

```sh
python3 main.py
```
